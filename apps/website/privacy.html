隐私说明

数据在谁手里

更新于 2026-11-13

一句话

TeachForge 没有账号体系，也没有我们的服务器。你的资料、会话、演练与课堂记录都存在你自己的电脑上； 只有调用模型时，当轮相关的上下文会发送给你配置的 DeepSeek API。

客户端

  • 不要求注册、登录，不收集手机号、邮箱或身份信息。
  • 数据默认存放在 ~/.tech-forge：SQLite 主库、资料副本、会话工作区、长期记忆、课堂记录。 该目录可用 TEACHFORGE_DATA_DIR 覆盖。
  • 后端只监听本机回环地址，所有请求需要本机令牌；界面层不接触令牌。
  • 客户端不内置第三方统计或广告 SDK。
  • DeepSeek API Key 以明文保存在本机 config.toml，界面默认遮蔽；它不会被发送到我们这里。

模型调用

每次对话、演练、课堂回应与总结生成都会请求 DeepSeek API，发送内容包含当轮需要的上下文： 你的提问或讲解、选取的资料片段、会话内的必要历史。资料文件本身留在本机，但被选入上下文的内容会离开本机。 因此不把本产品描述为“完全离线”。

本网站

官网是静态页面，不使用广告或跨站追踪脚本。当前未启用访问统计；若后续启用，只使用不依赖 Cookie 的聚合统计， 并在本页更新说明。站内没有表单，下载按钮直接指向安装包地址。
