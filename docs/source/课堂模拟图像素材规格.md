# 课堂模拟图像素材规格

**文档状态：** 制作规格，可直接交给生图模型使用
**对应设计：** [学习趣味性设计讨论](学习趣味性设计讨论.md) 的 3.7 节
**范围：** 课堂模式的背景、前景、三名学生立绘及派生图；不含 UI 图标（用 Phosphor）、不含报告页装饰（用 CSS/SVG）

## 1. 需要哪些图

| ID | 用途 | 尺寸（像素） | 比例 | 透明 | 优先级 |
|---|---|---|---|---|---|
| BG-01 | 教室背景（空镜，老师视角） | 2400×1500 | 16:10 | 否 | 必须 |
| FG-01 | 前景课桌条，遮住立绘下缘 | 2400×500 | 24:5 | 是 | 必须（可用低对比 CSS 渐变临时替代） |
| ST-01 | 学生「小林」半身立绘 | 900×1200 | 3:4 | 是 | 必须 |
| ST-02 | 学生「阿泽」半身立绘 | 900×1200 | 3:4 | 是 | 必须 |
| ST-03 | 学生「小满」半身立绘 | 900×1200 | 3:4 | 是 | 必须 |
| EXP-01…03 | 三人的「困惑」表情差分（只换头部） | 600×600 | 1:1 | 是 | 可选，P2 |
| AV-01…03 | 窄屏用的头像裁切 | 512×512 | 1:1 | 是 | 派生，不用生成 |

合计：**1 张背景 + 1 张前景 + 3 张立绘**即可跑通课堂模式。表情差分和头像都由这 5 张派生，不要额外让模型画第二套全身像，三张立绘的一致性比表情丰富度重要。

## 2. 风格基准

项目里已经有两套画风，课堂模式要**有意混用**并说明理由：

| 基准 | 来源 | 借用什么 |
|---|---|---|
| 角色画风 | `apps/desktop/src/assets/rehearsal-preparing.gif` | chibi 动漫、柔和赛璐璐上色、暖棕描边、圆润五官、干净的大色块 |
| 背景画风 | `apps/desktop/src/assets/sidebar-dreamy-peak.png` | 紫罗兰到暖白的空气感、扁平渐变、极低细节、大量留白 |

背景细节越少，三个立绘越容易统一，气泡文字也越清楚。禁止把背景画成照片级教室或高对比插画。

### 2.1 调色板（必须写进 prompt）

| 色名 | HEX | 用在哪 |
|---|---|---|
| 背景紫白 | `#f7f4ff` → `#efe9ff` | 墙面、天空、大面积底色（约 70%） |
| 暖光 | `#fff1d8` / `#ffdfac` | 左上窗光、桌面反光（约 10%） |
| 中性紫灰 | `#eae7f4` / `#a7a1ba` | 地面、桌沿、远景物体（约 20%） |
| 品牌紫 | `#6f43dd` / `#c7b2ff` | 学生服装、桌面小物点缀 |
| 蜂蜜色 | `#f5a441` / `#ffc978` | 暖色服装、围巾、光斑 |
| 角色肤色 | `#f7dcc8` | 三人统一肤色 |
| 发色 | `#3f2f33` / `#2f2733` / `#5a3d33` | 三人区分，均为低饱和深色 |
| 描边 | `#3b2f33` | 仅角色使用，1.5–2px 视觉粗细 |

约束：画面里不出现高饱和红、绿、青；不出现纯黑；不出现渐变网格或噪点纹理。

### 2.2 光线

- 主光来自画面左上方，暖白（`#fff1d8`），强度低，不产生硬阴影。
- 环境光偏紫，整体明度高、对比低，接近侧栏插画的晨光。
- 立绘**不带投影、不带地面、不带背景**；落位阴影由 CSS 画一个 8% 透明椭圆。

| 参数 | 值 | 说明 |
|---|---|---|
| 舞台比例 | 16:10 | 与设计稿一致；实现用 `aspect-ratio` |
| 立绘显示高度 | 舞台高度的 48–52% | 以头顶到切边计，底部被课桌条遮住 |
| 水平中心 | 22% / 50% / 78% | 三张立绘的包围盒中心 |
| 立绘底部 | 舞台高度的 86% | 下方 14% 由 FG-01 压住 |
| 气泡 | 顶部 33% 区域，宽 ≤ 38% | 不遮挡任何一张脸 |
| 人物眼高 | 舞台高度的约 42% | 三人必须齐平 |

BG-01 必须遵守：

- 132px（33%）以上的区域保持安静：只有墙、窗光、淡云或空白，不要挂画、书架、绿植。
- 320px（80%）以下不要有高对比物体，给前景课桌条留位置。
- 不要画学生、椅子上的书包或任何人形轮廓，否则会和立绘叠出“双人”。
- 透视平视，不要俯视或广角畸变。

## 4. 生成流程（三张立绘保持一致）

1. **先出 BG-01**，选定一张作为整组风格参考图。背景的色温和光线决定立绘的光。
2. **再出 ST-01**，把它和 BG-01 一起作为 reference image，生成 ST-02、ST-03。所有图的 prompt 前缀逐字相同，只替换角色段落。
3. 模型支持时固定 **seed**；不支持就用同一参考图 + 同一风格前缀，多出几张挑最一致的。
4. **不要一次生成三个人的合影再切图**：边缘会带背景残影，头身比、光源、线宽都会不一致。
5. 抠图：背景是纯色（推荐 `#00FF00`，角色服装里禁止出现绿色）→ 用 rembg 或设计软件去背 → 检查发丝、眼镜框、手指边缘的半透明像素。
6. 统一缩放：以“头顶到切边”的高度对齐，输出 900×1200，底部留 24px 透明余量，人物居中。
7. 在 `#f7f4ff` 画布上按 22%/50%/78% 摆三张看一遍，确认光源方向和大小一致。

```text
soft warm light from the upper left, no harsh shadows, no texture, no noise.
Palette: lavender #f7f4ff #efe9ff, muted lilac #eae7f4 #c7b2ff, brand violet #6f43dd,
honey #ffc978 #f5a441, warm skin #f7dcc8, dark brown hair #3f2f33.
```


### 5.7 ST-03 小满（怀疑型）

```text
Half-body chibi anime character, skeptical student, wavy shoulder-length hair #5a3d33, one eyebrow
slightly raised, arms loosely crossed, dark ink cardigan #46405c over a cream shirt, honey scarf
#ffc978 around the neck, warm skin #f7dcc8, slight smirk, looking at the viewer, waist-up,
centered, front view, isolated on solid #00FF00 background, no shadow, no background, no text.
```

角色关键：**V 形轮廓 + 深色开衫 + 围巾**。她负责质疑前提：“如果前提不成立呢？”

### 5.8 EXP-01…03 困惑表情（可选）

```text
Close-up head and shoulders of the same character as the reference image, same hairstyle, same
clothing colors, slightly tilted head, small confused expression with one raised eyebrow and a
tiny sweat drop, soft chibi anime style, isolated on solid #00FF00 background, no text.
```

只生成头部，实现侧用 CSS 叠在立绘头部位置；如果三次生成的脸对不上，直接放弃差分，改用 CSS 的小问号标记。**不要为了表情差分牺牲立绘一致性。**

## 6. 验收清单

- [ ] 透明通道正常：发丝、眼镜框、手指边缘无白边或绿边。
- [ ] 三张立绘头身比一致，眼高在同一水平线（误差 < 2% 舞台高度）。
- [ ] 光源方向一致（左上暖光），没有一张是正面平光或右侧光。
- [ ] 三张立绘的线宽、肤色、描边色一致。
- [ ] 200px 高缩略图下，三人的剪影仍可区分（连帽衫 / 背心眼镜 / 开衫围巾）。
- [ ] 背景上部 33% 没有挂画、书架、绿植等抢注意力元素。
- [ ] 背景里没有人物、椅子上的书包或镜面反射的人影。
- [ ] 所有图片内没有文字、字母、数字、logo、签名。
- [ ] 立绘没有投影、地面、背景残影；没有手套式的糊手指。
- [ ] 三张立绘与背景叠在一起时，色温一致，没有一张偏黄或偏蓝。
- [ ] 文件体积：BG ≤ 400 KB，FG ≤ 200 KB，单张立绘 ≤ 250 KB（PNG-32；转 WebP 需复查边缘）。

## 7. 落地

| 项 | 约定 |
|---|---|
| 目录 | `apps/desktop/src/assets/classroom/` |
| 命名 | `bg-classroom.png`、`fg-desks.png`、`student-lin.png`、`student-ze.png`、`student-man.png` |

| 遮罩 | 立绘底部由 FG-01 压住；不裁剪立绘文件本身 |
| 降级 | 窄于 900px 时只使用头像裁切（AV-01…03）+ 消息列表，背景图隐藏 |

## 8. 常见失败与替代

| 失败 | 处理 |
|---|---|
| 模型不给透明背景 | 用纯色背景 + 抠图；绿色键控时禁止服装出现绿色 |
| 三张立绘脸/比例不一致 | 先做一张“三人 lineup”当参考图，再逐张生成；仍然不一致就统一改成同班服（同款不同色），弱化面部差异 |
| 背景透视太强，立绘站不住 | 换更平的背景，或让 FG-01 更高（占到舞台 20%），用课桌遮挡下半身 |
| 模型在画面里加文字 | 换 seed 重出；后期用内容感知填充去掉，禁止保留“AI”“CLASS”等字样 |
| 立绘带阴影/地面 | 抠图时一并去掉；落位阴影统一由 CSS 椭圆负责，保证三张一致 |
| 背景太花，气泡看不清 | 降低背景对比或给气泡加 `bg-white/85`；不要靠加深气泡边框解决 |
