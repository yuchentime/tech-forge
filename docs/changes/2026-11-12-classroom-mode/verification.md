## 4. 进入动效（浏览器 1400×800，冻结动画时间轴逐帧截图）

| 时间 | `--tf-stage-reveal` | 观察 |
|---|---|---|
| 0ms | 0% | 中心一颗柔光圆点，四周保持暗底 |
| 160ms | 12.0% | 圆形柔光扩大到中间学生的上半身 |
| 320ms | 50.0% | 覆盖大部分教室，四角仍暗；控件开始淡入（透明度 0.48） |
| 480ms | 88.0% | 只剩四角边缘收口 |
| 640ms | 100% | 四角完全覆盖，无暗角；控件完全显示 |
| 结束后 | 100% / `scale(1)` | 静止画面与无动效状态逐像素一致（无残留遮罩） |

补充：

- 早期版本用未注册属性 + `cubic-bezier(0.2, 0.8, 0.25, 1)`，实测 90ms 已达 160% 半径、150ms 内铺满整屏，读不出展开过程；改为注册属性 + 现在这条曲线后才有连续的波纹。
- 用 `76%` 作为终点（按"圆角在 71%"估算）时静止画面四角残留暗角，说明百分比半径的基准不是该估算；改用 `circle farthest-corner` 后 100% 即最远角，暗角消失。
- `prefers-reduced-motion: reduce`（CDP `emulateMediaFeatures`）：`animationName: none`、`maskImage: none`、`--tf-stage-reveal: 100%`，舞台完整可见。

## 5. 消息输入框（浏览器 1400×800）

| 检查 | 观察 |
|---|---|
| 位置与尺寸 | 舞台 1400×788 内 644×181，`left 27% / right 73% / top 74% / bottom 97%`，落在插图前景课桌区域（红框约 29%–75% 宽、76%–97% 高） |
| 卡片 | 与对话输入框同款白卡、`rounded-3xl`、1px `ink-200`，额外 `shadow-card`；聚焦时只把边框换成 `brand-500` |
| 控件 | 表单内按钮只有「发送」（空文本时 `disabled`），没有「附件」 |
| 占位符 | 「写下你准备讲给学生的内容…」 |
| 斜杠命令 | 输入 `/` 后 `[aria-label="斜杠命令"]` 不存在，文本保持 `/` |
| `Esc` | 焦点在输入框内按 `Esc`：仍在课堂模式、文本保留；点击画面后再按 `Esc` 才退出 |
| 草稿 | 课堂输入 `/` 后退出，对话输入框的值为 `/`，且对话输入框仍有「附件」与斜杠菜单（未受课堂改动影响） |
| 固定高度 | 输入 360 字（对话）与整段长文（课堂）后，textarea 高度都保持 96px；对话 `scrollHeight 128 / clientHeight 96`、课堂 `416 / 96`，即内容滚动而不是撑高 |
| 滚动条 | 真实 Electron 窗口（125% 缩放）里 textarea 的 `offsetWidth - clientWidth = 10`，截图右缘可见 `ink-300` 圆角滑块；无头浏览器默认隐藏滚动条，不能作为可⻅性依据 |
| 斜杠命令回归 | 换成普通 textarea 后，对话里输入 `/` 仍打开菜单，Enter 选中后清空文本并挂上命令胶囊 |

### 课堂交互原型（浏览器 1400×800）

| 状态 | 输入框 | 讲稿卡 | 学生气泡 |
|---|---|---|---|
| `composing` | 181px 高（文本域 96px），占 74%–97% | 无 | 无 |
| 发送后 `sent` | 66px 高（单行文本域 40px），占 88.6%–97% | 128px 高，占 71.4%–87.6%，正文 4 行内部滚动 | 480×70，占 27.1%–36.0%，居中于中间学生上方 |

- 输入 212 字后按 `Ctrl + Enter`：状态切到 `sent`、讲稿卡显示「讲稿 · 212 字」、回复框自动获得焦点。
- 回复按下发送：气泡消失、回复清空、讲稿卡保留。
- 「重新讲解」：回到 `composing`（输入框回到 181px、讲稿卡与气泡消失）。
- 讲稿卡与输入框同宽 644px，停靠区不遮挡三名学生的脸。

### 消息侧栏与 3 秒淡出（浏览器 1400×800）

| 检查 | 观察 |
|---|---|
| 初始 | 侧栏折叠（`inert`、`opacity 0`）、右下角按钮无角标；输入框 181px、无气泡 |
| 发送后 | 讲稿浮层出现且不透明度 1；输入框 66px；气泡出现；右下角角标「2」 |
| 3.6s 后 | 浮层消失（`aria-label="刚发送的讲稿"` 不再存在），角标仍为 2 |
| 展开侧栏 | `aria-expanded` 按钮消失、抽屉 `inert` 变 false；列表两条：`老师 · 讲稿`、`小满`；自动滚到底 |
| `Esc`（侧栏开） | 只收侧栏，仍在课堂模式；再按一次才退出 |
| 回复发送 | 角标变「3」、气泡消失、抽屉新增 `老师` 条目 |
| 重新讲解 | 回到 `composing`（输入框 181px）、消息清空（0 条）、抽屉关闭 |
| 尺寸影响 | 抽屉展开时舞台仍为 1400×788，无缩放/留边；只覆盖右侧 |
| 降级 | `prefers-reduced-motion` 下淡出动画关闭，仍由 3.6s 定时器移除浮层 |

| 检查 | 观察 |

## 6. 已知行为

- React 开发模式（StrictMode）下挂载/卸载各执行一次，日志可见 `enter → exit → enter`；生产构建只执行一次。几何结果不受影响。
- 不写自动化测试覆盖 `will-resize`（需要真实窗口与指针拖动）；几何纯函数由单测覆盖，交互行为由上述实机记录覆盖。
