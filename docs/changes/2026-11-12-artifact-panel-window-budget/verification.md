### 2. 真实窗口几何（独立 Electron 进程复刻 main 的路径，不启动后端）

环境：Windows 11，125% 缩放，`workArea` 2048×1104。

| 观察 | 结果 |
|---|---|
| 边框差 | 实测 14（不是 16） |
| 扩到内容 1264 | 外层 1279、内容 1264；连续 6 轮扩/还原逐轮**完全一致**（1279×823 → 962×823，内容 1264 → 948） |
| 请求 4000 | 夹到工作区 2048、内容 2034 |
| 只传 `{x,width}` | 高度每轮 +2~3px（822→826→829→831）：Electron 会从 content rect 反推高度再补边框 |
| 每轮写回"上一轮读回的 bounds" | 仍漂：还原宽 962→963→964、高 823→825→826 |
| 每个窗口只采样一次 baseline，扩与还原都由它派生（当前实现） | 稳定，无累积漂移 |

结论与本轮修正已写入 [design.md §6.4](design.md)：`windowBaselines` 每个窗口只采样一次，`will-resize` 才失效；还原只比较 `x`/宽度。
